RobustMQ is an open-source message queue designed for cloud-native deployments and converged messaging workloads. I contribute to the project across the areas where a messaging system has to be both fast and understandable: protocol compatibility, storage, scheduling, operations, and developer experience.

The project is written primarily in Rust and is a practical place to explore the trade-offs behind durable messaging systems.
